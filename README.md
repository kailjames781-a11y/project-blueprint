# Project Blueprint

صمّم التطبيق الكامل لمنصة Zeruvo وكلاء ذكاء اصطناعي يبنون مشاريع برمجية كاملة — المستخدم يوصف فكرته بلغته الطبيعية، والوكلاء يكتبون خطة تنفيذ مرحلية، ثم الكود، ثم الاختبارات، ثم يسلّمون مستودع GitHub شغّال؛ مع نظام رصيد (سعر لكل 100 رصيد)، مدفوعات، اشتراك، وإشعارات. المطلوب تصميم كل صفحات التطبيق معاً كهوية واحدة متسقة.

القاعدة الإلزامية: التصميم يجب ألا يشبه إطلاقاً قوالب SaaS الجاهزة ولا يُقرأ كتصميم مولّد بالذكاء الاصطناعي (بلا خلفيات داكنة مع لمسة نيون، بلا بطاقات مستديرة متطابقة، بلا عناوين مركّزة مع تدرجات). اختر زاوية مفاهيمية واحدة مستمدة من طبيعة المنتج — وثيقة مواصفات حية، ورشة بناء، مسودة هندسية، أو لوحة تحكم ورشة — والتزم بها حرفياً في كل صفحة وكل تفصيلة: التايبوغرافي هو الشخصية الأساسية، المحتوى مكتوب بلغة مباشرة من منظور المستخدم، أسماء الأزرار تقول ماذا يفعل الزر فعلاً، عنصر لا يُنسى واحد قوي لكل صفحة والباقي هادئ ومنضبط، تجاوب كامل مع الموبايل ولوحة المفاتيح.

قيود صارمة لا تُخترق: ممنوع الإيموجي نهائياً وممنوع أي تدرجات لونية نهائياً في أي مكان (خلفيات، أزرار، أيقونات، حدود، ظلال، حالات hover، كل شيء).

الصفحات المطلوبة:

Landing (/) — زائر أول مرة يفهم خلال ثوانٍ ماذا تفعل المنصة ولماذا تهمّه. افتتح بأكثر ما يميز المنتج: حالة مشروع حية أو مقطع من خطة تنفيذ حقيقية (بنود done / active / queued)، بدل هيرو تسويقي عام. الميزات كتتابع مراحل مرقّم لأن المحتوى فعلاً تتابع: التخطيط، التنفيذ، الاختبار، التسليم. قسم أسعار مبني على الرصيد: سعر واحد لكل 100 رصيد، بدون باقات معقدة. فوتر بسيط. زر أساسي واضح للتسجيل وزر ثانوي للدخول.

Register (/register) — تسجيل بالاسم الكامل والبريد وكلمة المرور وتأكيدها. عنوان الصفحة بيان بسيط وليس دعوة حماسية ("أنشئ حسابك وابدأ أول مشروع"). التحقق يظهر كرسائل واضحة تحت كل حقل: كلمة المرور ≥ 8 أحرف، تطابق الحقلين. الخطأ الشائع (البريد مستخدم مسبقاً) يظهر برسالة توجّه المستخدم لتسجيل الدخول بدلاً من إحباطه. بعد النجاح: التحقق من البريد قبل الدخول، مع رسالة "أكّد بريدك" الواضحة. زر العودة لتسجيل الدخول.

Login (/login) — بريد وكلمة مرور وخيار "تذكرني" (checkbox). رسالة خطأ واحدة عامة تصلح للبريد الخاطئ وكلمة المرور الخاطئة، بدون كشف وجود الحساب. روابط: نسيت كلمة المرور، إنشاء حساب جديد. بعد النجاح: الانتقال إلى لوحة المستخدم.

Forgot password (/forgot-password) — حقل بريد واحد وزر "أرسل رابط الاستعادة". بعد الإرسال: رسالة موحّدة نفسها سواء وُجد البريد أم لا (لا تكشف وجود الحساب) — "إذا كان هذا البريد مسجلاً، أرسلنا رابط إعادة التعيين". رابط عودة لتسجيل الدخول.

Reset password (/reset-password) — تُفتح من رابط الاستعادة في البريد. حالة انتظار أثناء التحقق من الرابط. إذا الرابط غير صالح أو منتهي: صفحة واضحة تشرح المشكلة وزر "أرسل رابطاً جديداً". إذا الرابط صالح: حقلا كلمة المرور الجديدة وتأكيدها مع نفس قواعد التحقق.

Admin login (/admin/login) — صفحة دخول الإدارة. يجب أن تبدو مختلفة بصرياً عن دخول المستخدمين (مثلاً: إطار مزدوج، علامة "منطقة إدارية"، نبرة أصرح وأجوَف) لكن ضمن نفس الهوية. بعد الدخول، إذا الحساب ليس إدارياً: رسالة "هذا الحساب لا يملك صلاحيات الإدارة" ورفض فوري، وسلوك عودة لصفحة البداية.

User dashboard (/dashboard + /dashboard/profile + /dashboard/credits + /dashboard/subscription + /dashboard/payments + /dashboard/connections + /dashboard/download + /dashboard/notifications) — بعد دخول المستخدم، شريط جانبي بالبنود: نظرة عامة، الملف الشخصي، الرصيد، الاشتراك، المدفوعات، الاتصالات (ربط GitHub مستقبلاً)، تحميل تطبيق سطح المكتب، الإشعارات. في هذه المرحلة كل الصفحات placeholders بسيطة تُظهر العنوان وجملة "هذه الصفحة تُبنى في مرحلة لاحقة" — لكن التصميم يجب أن يجعل بنية اللوحة واضحة (شريط جانبي، منطقة محتوى، زر خروج في الأسفل).

Admin panel (/admin + /admin/plans + /admin/users + /admin/payments + /admin/pricing + /admin/coupons + لوحات المزودين والموصلات والإشعارات والأدوار) — نفس منطق لوحة المستخدم لكن للإدارة: باقات، مستخدمون، مدفوعات، أسعار، كوبونات، مزودو AI، موصلات، إشعارات، أدوار. كلها placeholders الآن، لكن نفس شرط وضوح البنية.

اكتب أيضاً: كل النصوص بالإنجليزية، لكل صفحة عنصر واحد لا يُنسى (اللحظة البصرية المميزة) — مثلاً على الهبوط مقطعة خطة تنفيذ حقيقية، على admin login علامة حدود إدارية، على register... إلخ. التسلسل البصري واضح: العنوان، ثم الملخص، ثم الدعوة للفعل. العناوين بتايبوغرافي هوية، والمتن قابل للمسح الضوئي سريعاً. ممنوع نهائياً الإيموجي والتدرجات اللونية — استبدلها بتايبوغرافي، حدود، مساحات بيضاء، ترقيم حقيقي، أو زوايا قطع حادة/مائلة إذا ناسب الزاوية المفاهيم
